# Start here: StrategyLab v2.0 Stage 1 acceptance candidate

Extract this ZIP to a **new folder** (not over the existing repository). In VS Code, open the folder containing `app.py`.

```powershell
python -m unittest discover -p "test_*.py" -v
python app.py
```

Expected: **50 automated tests**, then a separate PyQt6 desktop window. See `STAGE1_FINAL_NOTES.md` for the single consolidated Windows checklist and test caveats.
